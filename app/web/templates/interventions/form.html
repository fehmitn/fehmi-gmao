Demande d'intervention corrective
Tout équipement actif peut faire l'objet d'une demande, même s'il n'est pas encore affecté à une opération périodique.
Décrivez ce qui est constaté : le responsable de maintenance s'appuie sur cette description pour affecter l'intervention.
Circuit d'une intervention corrective.
  1. Un utilisateur décrit la panne (cette demande).
  2. Le responsable de maintenance affecte un technicien.
  3. Le technicien saisit l'heure de début, le compte rendu et l'heure de fin.
  4. Les pièces sont demandées puis consommées ; la sortie de stock est automatiquement tracée sur l'OT.
